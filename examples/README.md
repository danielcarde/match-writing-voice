# Synthetic example

The three messages in `synthetic/` are authored test fixtures, not a real user's corpus. They show lowercase, apostrophe omission, a practical explanation pattern, and a single possible “your/you're” slip. The single slip is not treated as an established habit.

Run:

```sh
python tools/demo.py
```

This writes an interpreted fixture profile, a readable guide, mode-specific example drafts, and check reports under `.local/demo/`. It exercises the workflow's mechanics. The script deliberately authors the profile traits; measurement does not infer them automatically.

Brief: “I can bring the projector to the library on Tuesday, but I need it back by 5 pm.”

| Mode | Demonstration |
|---|---|
| Faithful | yeah i can bring the projector to the library on tuesday, its just that i need it back by 5 pm. |
| Lightly edited | Yeah, I can bring the projector to the library on Tuesday. It's just that I need it back by 5 pm. |
| Adapted email | I can bring the projector to the library on Tuesday. I'll need it back by 5 pm. |

The example output is fixed for reproducibility, not generated by a hidden model call. New model writing and real author preference testing are separate activities.
