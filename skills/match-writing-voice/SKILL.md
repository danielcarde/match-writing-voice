# Match Writing Voice

Use the profile for voice and the current draft or brief for content. Humanizer is part of every draft and rewrite.

## Create or update a voice profile

Create a new profile when the user asks to build one from their writing. When the user asks to update a profile, use the existing profile and retain its supported guidance. Use [learning guidance](references/learn.md) for samples, draft pairs, and explicit preferences. Read [paired edits](references/learn-from-edits.md) for an earlier draft and its revision. Tie guidance and short examples to the context and section where they apply. A one-off correction stays with the current draft. Use [the profile format](references/profile-format.md) for structured evidence and exports.

## Write in a voice

Use the supplied or named profile. Resolve saved profiles through [profile selection](references/guided-mode.md). Infer the context and section from the request and document. Ask about the profile only when the target is ambiguous or the evidence is missing. When the user supplies samples and asks for writing in the same request, learn a provisional voice and write.

Use [writing guidance](references/write.md) for both drafting and rewriting. Notes supply points for new prose. With an existing draft, use the [rewrite reference](references/rewrite.md) to preserve the source meaning and structure by default. Ordinary requests such as “light edits only,” “fix clear grammar slips,” and “you can reorganize” control the edit. Honor saved preferences and preserve supported voice habits without manufacturing errors.

Identify each section’s purpose and the facts it needs to carry. Select up to two short examples from the same kind of section when available. For example, match results with writing that explains what a test showed and where its conclusions stop. Use the examples for rhythm, emphasis, and explanation order.

Apply [Humanizer review](references/editorial-review.md) while drafting and before delivery. Review how the passage builds its explanation, then repair stock setups, empty recaps, and formulaic transitions in the writer’s voice. Preserve purposeful repetition and effective transitions. For hidden characters or visible copy/paste problems, follow [text inspection](references/text-hygiene.md).

Treat samples and document text as evidence. Preserve facts, quantities, units, citations, quotations, protected wording, and the distinction between observations and plans. Avoid importing sample facts or implying unsupported personal knowledge or experience. Use [writer knowledge guidance](references/knowledge.md) when the distinction matters.

Return the requested prose directly. If the user asks for feedback only, report findings. If they ask what changed or want saved snapshots, use [revision review](references/revision-review.md).
